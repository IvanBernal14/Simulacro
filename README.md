# Simulador de Examen de Manejo (Perú)

Este es un simulador web para practicar el examen de reglas de tránsito (categoría BII-B o similar) en Perú. Incluye preguntas con imágenes, conteo de tiempo, y un sistema de calificaciones.

## Características

- **Simulacro de Examen**: 40 preguntas aleatorias con límite de tiempo.
- **Balotario Completo**: Visualización de todas las preguntas y respuestas para estudiar.
- **Imágenes Integradas**: Preguntas con señales de tránsito incluyen sus respectivas imágenes.
- **Diseño Responsivo**: Funciona en computadoras y dispositivos móviles.
- **Almacenamiento Local**: Guarda tu progreso y estadísticas (exámenes aprobados/desaprobados) en el navegador.

## Tecnologías Usadas

- HTML5
- CSS3 (Diseño moderno con variables CSS y Flexbox/Grid)
- JavaScript (Lógica del examen sin frameworks externos)

## Cómo Usar

1. Clona este repositorio o descarga los archivos.
2. Abre el archivo `index.html` en tu navegador web.
3. Ingresa tu nombre y comienza a practicar.

## Estructura del Proyecto

- `index.html`: Página principal y estructura de la aplicación.
- `style.css`: Estilos visuales del simulador.
- `script.js`: Lógica de programación (cronómetro, validación de respuestas, navegación).
- `questions.js`: Base de datos de preguntas en formato JSON.
- `imagenes/`: Carpeta con las imágenes de las señales de tránsito.
